# 🚗 Vehicle Rental System (Tkinter & MySQL)

A desktop-based graphical application built with Python (Tkinter) and MySQL that allows users to register, log in, and book rental vehicles. 

## 🛠️ Tech Stack
* **Frontend:** Python Tkinter (GUI)
* **Backend Engine:** Python 3
* **Database:** MySQL Server (`mysql-connector-python`)
* **Assets:** Pillow (PIL) for image rendering

## ✨ Key Features
* **Authentication System:** Secure user registration and login modules (`register.py`, `login.py`).
* **Database Initialization:** Automated MySQL table generation and seeding scripts (`create_tables.py`, `db.py`).
* **Interactive Dashboard:** Personalized user dashboard upon successful login (`dashboard.py`).
* **Booking Module:** Intuitive interface to select vehicle models, categories, and calculate rental days (`booking.py`).
* **Dynamic GUI:** Full-screen optimized graphical interfaces with image rendering.
